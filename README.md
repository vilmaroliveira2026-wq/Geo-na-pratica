# Geo na Prática

Landing page de aulas particulares de Geografia para o ENEM, com o Prof. Vilmar de Oliveira — professor da rede estadual do Paraná, em Ponta Grossa (PR).

Projeto de portfólio front-end (HTML + CSS + JavaScript).

## O que tem na página

- Hero: "Geografia sem decoreba, direto pro ENEM"
- Sobre o professor
- Os 6 temas que mais caem no ENEM
- Questão de exemplo interativa, com resolução comentada
- Como funciona
- 3 planos: aula avulsa, pacote mensal e intensivo
- FAQ
- Montador de mensagem de contato

## Como ver

Abra o `index.html` no navegador, ou ative o GitHub Pages no repositório (branch `main`, pasta `/`).

Os valores dos planos são combinados no primeiro contato.
